# Independent fresh19 source artifact

This is a source-only, pre-output authoring artifact for the frozen deterministic terminology feasibility protocol. It contains exactly 19 new fictional Japanese records: two naturally distinct scenarios for each of the six declared safe families, plus the seven prescribed source-observable control types. All scenarios were written for this task without access to prior evaluation text or implementation test examples.

## Runtime projection

`fresh19_sources.json` contains `schema_version`, one complete ordered seven-entry `glossary`, and `records`. Every record contains only `id`, `scope_id`, `family_id`, and `source`. The loader must bind the exact shared glossary to every record, including the record with a foreign scope. It must never derive a glossary subset from a record, use metadata to override admission, or supply reviewer criteria to the candidate. The opaque family IDs preserve pairing without encoding a semantic answer.

`case_metadata.json` is a non-runtime description of the visible setting and ordinary Japanese source form. It provides no hidden plot, answer, sense label, role label, eligibility override, or per-record safety flag. The application-wide declarations remain unchanged.

## Naturalness and population limits

The proper-name pairs are natural direct addresses in six different situations. The technical-term pairs use workshop/equipment inventories, narrative identification, or standard task-label prose. Japanese vocative commas, enumeration commas, a narrative nominal predicate, and the conventional full-width task-label colon have their ordinary discourse functions; no spaces, padding, or orphan punctuation were added to defeat a boundary rule. Sources are complete short scenes or work-order records. No later trimming or membership adjustment is permitted after a failed preflight.

This deliberately narrow fictional population does not establish coverage for ordinary name-plus-particle constructions or unrestricted natural Japanese. It repeats some discourse forms across families, although each paired scenario differs in situation and proposition structure. The author is not a separate native-speaker panel. Exact novelty against unseen archives cannot be independently certified by this author because those sources were intentionally not read. Root must review naturalness, declaration consistency, source-only criteria and novelty before any output.

## Freeze and use boundary

The public receipt commits to the exact source bytes, metadata and this document, and to a separately held reviewer-criteria hash. It discloses neither the private criteria location nor contents. The source author did not run the policy, render prompts, call a tokenizer or model, read prior outputs or criteria, install tools, access the network, or publish anything. Independent literal-span and schema inspection used only the standard library.

Twelve intended carriers and seven controls are an authoring target, not a measured admission or token-budget result. Real full-template preflight remains required under the frozen protocol. Any mismatch is a stop condition, not permission to drop, rewrite or relabel a row. The immutable candidate must decide admission from the source, scope, complete glossary and global declarations only.
