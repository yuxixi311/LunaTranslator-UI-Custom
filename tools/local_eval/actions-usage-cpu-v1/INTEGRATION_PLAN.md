package and published prior runner are unchanged. The exact diff inventory
records adaptations against both frozen origins.

new usage project/workflow/state, exact source A/B shape and reviewed metadata.

only experiment-specific source, schedule, ledger, helper and public-output
wiring is adapted. The isolated bootstrap verifies every module before loading.

usage_worker_packets → usage_native_adapter → usage_runner_source, with exact
UsageCore accounting and the owned policy helper. The final coordinator uses
usage_evidence_validation and usage_public_exports. It never calls the old
88-row source loader, benchmark, candidate stage or reconciliation.

token gating. The child verifies the unchanged policy/guard/bank and finite row
state. Its concrete immutable packet factory is measured from its first source
read/write and binds the claim, source manifest, parent identity and deadlines.

The package has concrete metadata commitments and a fresh UUID, but no claim.

bindings, not missing algorithm implementation. Source and workflow publication
and one activation require the separately reviewed root release.

hosted ephemeral VM and job timeout are residual platform backstops only;
unknown pre-exec cleanup never becomes a pass. No new containment design or
exact hosted-image-version prerequisite is introduced.
