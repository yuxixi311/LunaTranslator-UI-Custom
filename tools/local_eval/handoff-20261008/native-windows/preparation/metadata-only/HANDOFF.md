## 结果边界

- Torch index 若正常提供目标链接，可核实文件名与 index 所声明的 SHA256。index 通常没有 wheel 字节数或完整依赖，因此 Torch 大小、依赖与许可明确保留 UNKNOWN
- PyPI JSON 提供四个候选 wheel 的大小与 SHA256，并保留发布级 Requires-Dist、Requires-Python 和许可声明。它们没有经过 wheel 本体或 wheel 专属 METADATA 验证
- 不求解环境标记、extras 或传递依赖，不选择任何新增包，不声称上述声明满足完整 Windows 依赖闭包
- 未下载 wheel，哈希是来源声明，不是本地文件校验结果；尚不能证明安装、导入、GPU或实际模型兼容
- 120秒是监督器运行预算，不是操作系统级硬实时保证；进程启动、系统挂起和最终报告写出可受操作系统影响。到期后终止该脚本自己启动的单一工作进程，不终止其他应用；工作进程不会产生后代进程。报告 worker_exit_confirmed 必须为 true 才可声明退出确认
- 字节限制针对读取的元数据响应体，不包括 TLS/HTTP头部及网络协议开销。总量上限8 MiB，五请求与每次1 MiB的联合约束实际上更严格。达到单响应上限即保守停止
- 收集失败只导出固定白名单中的 error_code；意外异常统一为 UNEXPECTED_ERROR，不导出异常名称、消息或参数
- 拒绝 JSON 重复键、非有限数字和类型不正确的 Requires-Python/许可字段；连接、响应头及响应体阶段超时的假响应回归均须停止，不能报告成功

若想完整锁定依赖，需要另行设计可被允许的官方元数据来源与求解方式。尤其 Torch wheel 大小不能从当前允许的 index 链接推断；不得借“元数据”名义再次请求已被拒绝的 wheel 端点。
